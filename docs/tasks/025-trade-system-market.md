# Feature: Trade system and Market building

**Status:** Not started

## Description

A trade system, unlockable via the skill tree, built around a new Market building that exchanges resources for currency.

## Requirements

- New Market building that lets the player sell resources for currency and buy resources with currency.
- By default, resources trade for a coin-like currency.
- Individual trades/exchange rates are unlocked one at a time via the skill tree.
- Default example rate: 10 rock = 1 coin.
- Later addition: an automated market (à la Age of Empires) where players can spend coins to buy resources without manual trading.
