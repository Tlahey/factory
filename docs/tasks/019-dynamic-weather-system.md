# Feature: Dynamic weather system

**Status:** Not started

## Description

A dynamic weather system that affects energy production of weather-sensitive buildings like solar panels and wind turbines.

## Requirements

- Cloudy days reduce solar panel output; windy days increase wind turbine output.
- Support multiple weather types: sun, clouds, rain, wind.
- Each weather type has a specific, defined impact on the output of the buildings it affects.
- Weather must be visible to the player via appropriate visual and audio effects.
