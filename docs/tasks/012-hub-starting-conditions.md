# Feature: Hub starting conditions

**Status:** Not started

## Description

The game should start with the Hub placed at the center of the map, deliberately isolated from nearby rock to force the player to explore.

## Requirements

- Place the Hub at the map's center at game start.
- Ensure no rock resources spawn in the immediate vicinity of the Hub.
- The Hub cannot be removed or moved by the player.
- The Hub must not appear in the list of buildable buildings.
