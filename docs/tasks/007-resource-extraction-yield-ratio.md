# Feature: Per-resource extraction yield ratio

**Status:** Not started

## Description

Resources should have a production/yield ratio that influences extractors, adding variance to extraction output.

## Requirements

- Add a yield ratio to resource definitions that affects extractor output.
- Rock: randomly extracts at ×0.5 or ×1.
- Design the system so other resources can later support additional ratios (e.g. ×1.5).
