# Feature: Scripted intro to bootstrap starting rock

**Status:** Not started

## Description

Players currently have no way to obtain starting rock without equipment. Proposed solution: a scripted opening scenario where an NPC talks to the player and gathers rock on their behalf.

## Requirements

- Add a scripted intro sequence where an NPC speaks to the player at game start.
- The NPC gathers a small amount of rock for the player.
- Once enough rock has been gathered, the NPC is struck by lightning and dies.
- For the rest of the playthrough, the NPC's ghost narrates/guides the player.
- The player should end the intro with enough resources to begin building.
