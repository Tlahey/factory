# Feature: Minimap

**Status:** Not started

## Description

Add a minimap in the top-right of the screen showing the full map, the player's position, and constructed buildings.

## Requirements

- Render a minimap in the top-right corner showing the entire map.
- Show the player's current position on the minimap.
- Show constructed buildings on the minimap.
- Make the minimap clickable so the player can quickly navigate/fast-travel to a clicked location.
