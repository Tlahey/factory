# Feature: Constructor building

**Status:** Not started

## Description

A Constructor building that crafts new items from other items, following the same UI/config pattern as the Furnace.

## Requirements

- Uses the same interface pattern as the Furnace (recipe selection, progress, queue).
- Config structure mirrors the Furnace's config.
- Visual model shows a press stamping downward (illustration TBD).
- Example recipe: 1 Iron Ingot, 4 seconds → 1 Iron Rod.
- Upgrades purchasable in the Hub to speed up the crafting process.
- Blueprints purchasable in the Hub to unlock additional craftable recipes.
