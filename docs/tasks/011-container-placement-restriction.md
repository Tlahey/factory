# Feature: Restrict initial Container placement to next to the Hub

**Status:** Not started

## Description

At the start of the game, the Container must be placed adjacent to the Hub and cannot be relocated elsewhere until unlocked via the skill tree.

## Requirements

- Restrict Container placement to tiles adjacent to the Hub while the relevant skill-tree upgrade is locked.
- Add a skill-tree upgrade that lifts this restriction, allowing free placement/relocation afterward.
