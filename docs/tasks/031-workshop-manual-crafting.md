# Feature: Workshop for manual crafting

**Status:** Not started

## Description

Add a Workshop near/inside the Hub for manually crafting items that don't require a furnace.

## Requirements

- New Workshop structure located near or inside the Hub.
- Player places one item into the Workshop, which crafts it into another item.
- Crafting is manual (player-triggered), not an automated production line.
