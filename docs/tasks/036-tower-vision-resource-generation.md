# Feature: Tower building for vision and resource generation

**Status:** Superseded by [037-multi-island-exploration-progression.md](037-multi-island-exploration-progression.md) (the resource-generation-in-revealed-zone idea from this file was not carried over — flagged there as a follow-up decision)

## Description

A Tower building that expands vision in a circular radius around it and randomly generates resources within that zone.

## Requirements

- Placing the tower expands visible map area in a circular radius around it.
- Resources randomly generate within that revealed zone.
- For game balance, only lower-tier resources spawn this way (not the most valuable ones).
- Resource rarity increases the further the zone is from the starting Hub.
