# Feature: Underground conveyor

**Status:** Not started

## Description

An underground conveyor variant that lets resources pass beneath another conveyor at the surface.

## Requirements

- Shares the core logic of regular conveyors.
- Requires its own skill-tree unlock before it can be built.
- Must be placed aligned with an existing surface conveyor.
- Spans 3 tiles of width: entry, passage (underground), exit.
- Takes a conveyor as input and outputs to another conveyor.
- Flow direction and handling match regular conveyors.
