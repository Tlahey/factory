# Feature: Starting iron ore and coal deposits

**Status:** Not started

## Description

The starting map should include one unlimited iron ore deposit and one unlimited coal deposit, placed to encourage exploration and base planning.

## Requirements

- Place exactly one iron ore deposit and one coal deposit on the starting map, at strategic locations.
- Both deposits are unlimited, so players can collect from them indefinitely.
- Surround each deposit with natural obstacles (rocks, trees) to make access harder.
- Make deposits visually distinct so players can easily identify them.
