# Feature: Hidden rare minerals inside rock tiles

**Status:** Not started

## Description

Rock tiles should occasionally hide a rare mineral drop, revealed once the tile is fully depleted, unlocking an upgrade.

## Requirements

- When a rock tile is fully depleted, there's a chance it reveals a special item.
- The special item unlocks an upgrade (e.g. an Extractor upgrade).
- This must be genuinely rare — target around a 0.1% chance.
